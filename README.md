# B1Boost 🚀

Un asistente de automatización discreto que te ayuda a repasar conceptos clave de inglés para dar el salto del nivel A2 al B1, mediante notificaciones emergentes nativas en tu escritorio.

## 🏗️ Estructura del Proyecto

Asegúrate de tener tus archivos organizados de la siguiente manera:

```text
B1Boost/
├── data.py          # Cerebro: Base de datos con las tarjetas de estudio
├── notifier.py      # Boca: Lógica que interactúa con las notificaciones del OS
├── main.py          # Corazón: Orquestador y control del temporizador (loop)
└── requirements.txt # Dependencias del proyecto
